# מדרום

מערכת קניון דיגיטלי מבוססת React, TypeScript, Cloudflare Workers ו־D1, עם API שנבנה מ־Pages Functions.

## מצב נוכחי

הגרסה המעודכנת שהועלתה ב־5 באוקטובר 2026 משמשת בסיס לקוד הנוכחי, כולל עדכוני הממשק שנעשו ב־Cloudflare. הבנייה שבקובץ ההעלאה תאמה לבנייה שהוגשה מהאתר החי בעת הבדיקה. המקור הישן נשמר בנפרד בענף הלא פעיל `archive/legacy-auth-2026-10-05`.

המערכת כוללת קטלוג ציבורי, חנויות, מוצרים, סל, בקשות רכישה ללא חיוב, אזור סוחר, אזור מנהל ואזור לקוח. תשלומים אמיתיים עדיין חסומים במכוון עד לחיבור ספק סליקה Marketplace מאושר.

- משולש האימות (מייל, טלפון ו־Google) מופיע באזורי הלקוח, הסוחר והמנהל, כולל אימות מייל בקוד מתוך החשבון.

### בקשות רכישה

הצעת המחיר מחושבת בשרת מתוך מחירי ומלאי המוצרים ב־D1. בקשה יכולה להתפצל למספר חנויות. משתמש מחובר נשמר כבעל הבקשה, והיסטוריית הבקשות מופיעה באזור האישי. אין חיוב ואין שמירת מלאי בשלב זה.

### התראות

נוצר מרכז התראות פנימי למשתמשים. לקוחות ובעלי חנויות מקבלים התראות במערכת על בקשות רכישה רלוונטיות, עם מונה לא־נקראו וסימון התראה בודדת או כולן כנקראו.

### מדיה

מוצר יכול להשתמש בקישור HTTPS או בהעלאת JPG/PNG/WebP ל־R2 כאשר binding בשם `MEDIA` מוגדר.

## Cloudflare Workers

הגדרות ה־Worker ששמואל הוסיף נשמרו ב־`wrangler.jsonc`: השם `bsda`, נכסים סטטיים ב־`dist` ו־API תחת `/api/*`. `npm run build` בונה את אתר React ואת ה־Worker ב־`worker/index.js`. בפריסת Git יש להגדיר Build command: `npm run build`, ו־Deploy command: `npm run deploy`.

ה־D1 מוגדר כ־`DB` ומכוון למזהה שמואל סיפק: `99c74b64-0934-4c37-8133-fc8cf45ee92f`. החיבור מוגדר לפי ID בלבד; שם המסד לא נמסר ולא הומצא. `npm run deploy` בודק את הסכמה במצב קריאה בלבד, מחיל את המיגרציות עד 0009 ורק אז פורס. עבור העלאת מדיה יש להגדיר R2 binding בשם `MEDIA`; קישורי תמונות HTTPS עובדים גם בלעדיו.

`npm run deploy` דורש חשבון Cloudflare מחובר והרשאת D1 המתאימה. מסד שמכיל טבלאות של פרויקט אחר לא יעבור את הבדיקה; ה־ID הישן של `shmuelnode-db` חסום תמיד. פרטים וממצאי התשתית ההיסטורית ב־AUTH_SETUP.md. הבנייה והמיגרציות נבדקו מקומית; פריסה חיה וספקי האימות לא אומתו בסביבה זו.

`npm run auth:restore -- --source "/path/to/original.env"` בודק שחזור של הגדרות הספקים מהמקור הישן בלי לחשוף ערכים. החלה דורשת `--apply` וכניסה ל־Cloudflare; מייל Resend דורש שולח מדומיין מאומת. ראו AUTH_SETUP.md לפני ההפעלה.
