# תשתית המערכת הקודמת — עותק ייחוס

הקוד כאן הועתק מתוך `next (3).zip` ונשמר לצורך שחזור ספקים והשוואה. הוא לא פורס ולא חובר למסד האתר הפעיל. אין כאן נתוני משתמשים, חנויות או הזמנות, ואין מפתחות גישה.

`README.original.md` מתעד את הגרסה כפי שהתקבלה. הוא עשוי לתאר תכונות שאינן קיימות בקוד. מקור האמת לתשתית הוא `server/lib/mailer.js` (Resend), `server/lib/sms.js` (Worker SMS), `server/lib/googleAuth.js` ו־`server/routes/auth.js`.

הקוד ההיסטורי משתמש ב־Express, JWT וקובץ JSON; הוא אינו Worker Cloudflare. מודול הקודים ההיסטורי אינו מיועד להחליף את הגיבוב וה־nonce של המערכת החדשה. הגדרות לדוגמה נמצאות בקובצי `.env.example`; הערכים הסודיים הושמטו.

ראו את `REFERENCE_VERSION.md` בשורש לממצאי האתר החי, למיפוי הספקים ולבדיקות התאימות. הרישוי המקורי `UNLICENSED` נשמר ללא שינוי.
